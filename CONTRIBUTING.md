# Contributing

Thank you for your interest in contributing to Prompt Collector for Feishu.

Contributions are welcome, including:

- Bug fixes
- Documentation improvements
- Compatibility fixes
- Security improvements
- New extraction rules
- UI improvements

## How to contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test the extension locally.
5. Submit a Pull Request describing what changed and why.

## Security

Please do not include API keys, Feishu App Secrets, access tokens, or other credentials in Issues or Pull Requests.

If your contribution affects browser permissions, external network requests, credential handling, storage, or page-content processing, please clearly describe those changes in the Pull Request.
